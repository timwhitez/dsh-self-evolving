## Provider and reasoning-only diagnosis

The ACP-facing final assistant text is not a full raw DSH transcript. Raw session evidence contains real bash tool
calls and tool results; ACP intentionally exposes the committed assistant message while internal reasoning/tool events
remain in DSH evidence. Therefore whitespace or sparse ACP text is not evidence that the model returned only
reasoning. The `gpt2-codegolf` trials timed out while the model actively explored the task and are retained as invalid
outcomes. Proposal-side reasoning-only exhaustion was a separate recovery defect fixed by continuing the compatible
tool loop; changing reasoning effort was not the fix, and CPA source was not modified.
