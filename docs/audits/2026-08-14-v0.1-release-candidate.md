## Gate 5 — product CLI

The real route is frozen to requested `deepseek-v4-flash-zen`, effective `deepseek-v4-flash`, `high`, a 1,048,576
context window, a 32,768 output ceiling and compatible Chat Completions. Paid launch preflight covers private auth,
locked HTTPS route, Docker, Harbor, task materialization, writable private state, budget, code identity and clean
executable source.

Candidate source diffs are applied to the exact parent, compiled twice and atomically admitted. Bounded proposal,
protocol and build rejections feed classified evidence into replacement attempts. External evaluator reconciliation,
journal replay and cost settlement are idempotent.
