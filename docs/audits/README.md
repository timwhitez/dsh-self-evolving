# Historical audit identity

Files in this directory are immutable predecessor reports. References to `dsh-RSI`, `dsh-rsi`, `@dsh-rsi/*`,
legacy protocol strings and old absolute paths identify the exact v0.1/v0.1.1 artifacts that were audited. They are
intentionally not renamed: changing them would make the reports disagree with their bound commits and durable run
evidence.

The live project identity from v0.2 onward is `dsh-self-evolving`; see
[`../migration-v0.2.md`](../migration-v0.2.md).
