# v0.2 release gates

v0.2 is a bounded successor to the accepted v0.1/v0.1.1 release candidate. Historical gates and artifacts remain
unchanged; these gates cover the live identity, default provider and measurable engineering-effect claim.

| Gate | Required outcome                                                            | State    |
| ---- | --------------------------------------------------------------------------- | -------- |
| V2-A | every live product/package/CLI/protocol identity is `dsh-self-evolving`     | accepted |
| V2-B | default proposer route is DeepSeek official Responses with host credential  | accepted |
| V2-C | real model authors a unique child that passes trusted admission             | accepted |
| V2-D | fixed replay changes in the target mode and is stable in the preserved mode | accepted |
| V2-E | full regression, source release, SBOM/provenance/checksums and leak scan    | accepted |

## V2-B — Official provider

Freeze `https://api.deepseek.com/v1`, `deepseek-v4-flash`, Responses, high reasoning, 1,048,576 context, 32,768
maximum output and `store=false`. Read only `DEEPSEEK_API_KEY` in the trusted host. The networkless proposer never
receives the key. Codex configuration and CPA are optional compatibility surfaces, not defaults.

This historical acceptance covered the trusted proposer path. It did not prove task-candidate credential isolation:
the retired Gate 5 runtime co-located its key and candidate. `gate5-credential-broker-v2` repairs that separate path,
but its fresh official-provider revalidation is pending and is not implied by V2-B.

## V2-C/D — Low-consumption effectiveness

One real proposal must produce a distinct child that passes candidate tests, deterministic double build, Loader
solve/propose, fixed replay and offline capsule admission. The predeclared contract targets solve and preserves
propose. Pass only when the solve replay digest changes and the propose replay digest does not.

`ENGINEERING_EFFECT_VERIFIED` is limited to a measurable fixed-replay runtime effect. It is not evidence of a
Terminal-Bench score increase, sealed confirmation, leaderboard standing or SOTA.

## V2-E — Release closure

The clean source release passed checksum verification, no-Git extraction, one-command source setup, exact upstream
provenance, typecheck, UTF-8/link/secret readiness scans, real Loader/capsule smoke, official-adapter lifecycle and
CLI `init`/`status`. The distribution is Apache-2.0 source archive only; standalone npm packaging remains
`NOT_INCLUDED`.

## Optional post-release scope

K=10/K=80 search, larger task sampling, sealed confirmation, full-set evaluation and sustained score optimization
remain separately authorized post-release work.
